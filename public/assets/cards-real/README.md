# Cartas de Hi-Lo

Esta carpeta contiene 52 PNGs de marcador para el juego **Conteo Hi-Lo con cartas reales**. Sustituye cada archivo por la imagen de la carta correspondiente, manteniendo exactamente su nombre y la extensión `.png`.

Formato: `<rango>-<palo>.png`

- Rangos: `A`, `2` a `10`, `J`, `Q`, `K`
- Palos: `spades`, `hearts`, `diamonds`, `clubs`

Ejemplos: `A-spades.png`, `10-hearts.png`, `Q-diamonds.png`, `K-clubs.png`.

Los marcadores actuales están vacíos intencionadamente; puedes reemplazarlos directamente sin cambiar el código.
